# Third-party notices — review draft

The revisions below describe the official VGM base and its pinned dependencies. This inventory is not a license grant or a complete binary-distribution notice set. Retain original copyright, SPDX and license notices in sources and submodules. Include the applicable full license texts and attribution notices with any binary release, not merely links from this file.

Before refreshing or redistributing the current artifacts: confirm the scope for the exact base and schemas, resolve third-party art/assets and nested dependencies by actual source/assets and link map, preserve change and copyright notices, and supply all required full license/attribution notices. If GPLv3 applies, follow [its Corresponding Source terms (§§1, 6)](https://www.gnu.org/licenses/gpl-3.0.en.html), including the scripts and source needed to build and install the covered binaries. Do not assume GitHub's automatic archives contain the files behind Git submodule entries.

The four assets documented in the [independent VGM Display 0.3.1 pre-release](https://github.com/ANTONiO-eagle/hybridus-vgm-display/releases/tag/vgm-display-v0.3.1-preview) are unchanged. The existing VGM source archive predates the MIT addition and does not contain that root license text. This inventory does not relicense any package component.
